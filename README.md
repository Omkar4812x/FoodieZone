# 👑 FoodieZone — World-Class Michelin-Standard Luxury Dining Platform

> **An ultra-luxurious, 7-star gourmet restaurant web application featuring full-screen 4K AI video backdrops, automatic scroll-based sound management, an executive gold custom cursor, interactive catering menus with Sommelier wine pairings, and a VIP Concierge reservation portal.**

---

## ✨ Key Luxury Features

- 🎬 **4K Full-Screen AI Video Hero**
  - Immersive cinema-grade 4K gourmet video background (`hero-video.webm`).
  - Minimalist luxury typography with glowing gold accents.
  - **Animated Mouse Scroll Indicator** guiding visitors smoothly to explore the story.

- 🎵 **Smart Scroll-Based Audio Management**
  - Automatic video music playback on the Home page.
  - **Auto-Mute on Scroll**: Mutes automatically when scrolling down past the Hero section, and restores audio automatically when scrolling back up.

- 🖱️ **Executive Gold Custom Cursor & Magnetic Ring Trail**
  - Precision gold dot cursor with a smooth 60fps physics-delayed outer glass ring.
  - **Magnetic Target Hover**: Expands into a glowing gold target ring when hovering over interactive buttons, menu items, and links.

- ✨ **Global Twinkling Gold Star Particles**
  - 60fps canvas particle overlay rendering continuous subtle ambient gold star sparkles across all pages.

- 🍷 **Interactive Catering Menu & Sommelier Pairings**
  - Tabbed menu categories (**Breakfast**, **Brunch**, **Lunch**, **Dinner**).
  - Hovering and clicking menu items dynamically switches high-resolution dish photography.
  - Interactive popup modal detailing ingredients, chef tags, and curated **Sommelier Wine Pairing** recommendations.

- 👨‍🍳 **Authentic Head Chef Executive Showcase**
  - Features Master Chef Omkar Bhandalkar in an ornate executive gold-framed portrait, celebrating 30+ years of culinary artistry.

- 🪑 **Bespoke Table Reservation System & Atmosphere Chips**
  - Seating Atmosphere Selector chips (`🍷 Main Dining Room`, `⭐ VIP Chef Table`, `🌃 Rooftop Terrace`, `🗝️ Private Suite`).
  - Instant confirmation modal calculating date, time, party size, and chosen atmosphere.

- 💎 **VIP Concierge Culinary Club**
  - Privilege tasting menu subscription portal with custom toast notifications.

- 📱 **100% Fully Responsive & Mobile-Optimized**
  - Fluid mobile navigation with glassmorphic slide-out hamburger menu.
  - Touch-optimized video and audio unlocking for iOS Safari and Android Chrome.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom CSS Variables, Flexbox, CSS Grid, Glassmorphism).
- **Media**: 4K WebM/MP4 Video, High-Res WebP Culinary Assets, HTML5 Canvas 2D API.
- **Typography**: Google Fonts (*Playfair Display* & *Lato*).
- **Deployment**: Vercel ready (Zero-Config Static Hosting).

## 🚀 Quick Setup & Local Development

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Omkar4812x/FoodieZone.git
   cd FoodieZone
   ```

2. **Run Locally**:
   Open `index.html` directly in any modern browser, or run via VS Code **Live Server**.

---

## 🌐 Deploying to Vercel

This repository is pre-configured for instant static deployment on Vercel:

```bash
npx vercel
```

Or connect `https://github.com/Omkar4812x/FoodieZone` directly inside your **Vercel Dashboard**.
